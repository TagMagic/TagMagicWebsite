Documentation

• Overview
TagMagicAPI is a fast, lightweight audio metadata service designed for developers, creators, and platforms that need clean, accurate tags and updated album art. This documentation explains how the API works, what each plan includes, and how to integrate it into your workflow

• How It Works
TagMagicAPI processes your audio file, extracts metadata, updates missing or outdated album art (Developer & Pro plans), and returns clean JSON

The workflow is simple:

Send an audio file to the API

The API reads metadata

(Developer & Pro) The API finds and updates album art

You receive a clean JSON response

No files are stored — everything is processed and discarded instantly

Album Art Updating
(Album art updating is one of TagMagicAPI’s most important features)

• Here’s exactly what it does:

Detects missing or outdated album artwork

Finds clean, high‑quality cover art

Embeds the updated artwork directly into the audio file

Returns the updated artwork in the JSON response

Works automatically — no manual tagging required

*Available in: Developer Plan, Pro Plan
*Not available in: Free Plan

API Endpoints
POST /v1/tag

Upload an audio file and receive metadata + artwork (depending on plan)

Request:

Audio file (binary or multipart/form‑data)

API key in header

Response:

JSON metadata

Artwork (Developer & Pro)

Status codes for success or errors

Authentication
All plans use simple API key authentication.

Header Example:
Authorization: Bearer YOUR_API_KEY

Rate Limits

Pro: 50,000 requests/day

Error Codes
